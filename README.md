# Монтаж 360° · сайт для площадок с активностями

Статический сайт сервиса монтажа сферических 360° и обычных видеороликов. Основной контакт — звонок Александру; Telegram доступен как второй способ связи. Форм, квизов, отправки заявок, аналитики и серверной части нет.

## Локальный просмотр

Откройте index.html или запустите из корня проекта:

    python3 -m http.server 8765 --bind 127.0.0.1

Затем откройте http://127.0.0.1:8765/. Страница guest.html показывает пример просмотра и скачивания ролика гостем. Все ресурсы локальные; сборка и установка библиотек не нужны.

## Контент и медиа

- Номер +7 952 217-67-44 и https://t.me/GOODTOBEDONE подтверждены владельцем для этого сайта.
- MAX скрыт. Точную подтверждённую ссылку можно добавить в site-config.js; пустое или некорректное значение не создаёт кнопку.
- Четыре WebP в assets/photo-*.webp — иллюстрации ImageGen с подписями, не фотографии реализованных проектов.
- demo.mp4 — оригинальное синтетическое обычное видео: 8 секунд, без звука. Оно не является панорамной записью или реальным заездом.
- Настоящий сферический пример и реальные кейсы добавляются после проверки исходников и разрешений. Клиентские данные и необработанные материалы в репозиторий не включаются.

До 70% — возможная доля выручки от видеопродаж на согласованных условиях, не обещание чистой прибыли. Окупаемость предлагается рассчитать по цене, оплаченным заказам, доле площадки и расходам, без гарантированных сроков.
