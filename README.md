# Монтаж 360° · публичное демо сайта
Статический прототип сервиса, не рабочий канал приёма заявок или выдачи роликов. Откройте index.html; при проверке через HTTP также доступно guest.html.
Гостевой MP4 — оригинальная синтетическая иллюстрация, не реальный заезд. Камеры изображены условно; фотографии из исходного прототипа не входят в это демо. Бриф скачивается и копируется локально; его поля не передаются серверу.
Перед запуском сервиса отдельно подключите согласованный канал заявок, проверьте, что тестовая заявка дошла до ответственного, и используйте только согласованные кейсы. Данные клиентов и ссылки на их видео не должны попадать в публичный репозиторий.
