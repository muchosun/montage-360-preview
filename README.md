# Монтаж 360° · сайт для картинга и аттракционов

Статический сайт сервиса монтажа сферических 360° и обычных видеороликов. Основной контакт — звонок Александру; Telegram доступен как второй способ связи. Квизов нет. Контактные ссылки работают напрямую. Отдельная Метрика включается только на HTTPS-домене montazh360.ru, без Вебвизора; настройка описана в INTEGRATIONS.md.

## Локальный просмотр

Откройте index.html или запустите из корня проекта:

    python3 -m http.server 8765 --bind 127.0.0.1

Затем откройте http://127.0.0.1:8765/. Страница guest.html показывает пример просмотра и скачивания ролика гостем. Все ресурсы локальные; сборка и установка библиотек не нужны.

## Контент и медиа

- Номер +7 952 217-67-44 и https://t.me/GOODTOBEDONE подтверждены владельцем для этого сайта.
- MAX скрыт. Точную подтверждённую ссылку можно добавить в site-config.js; пустое или некорректное значение не создаёт кнопку.
- На первом экране показаны кадры из опубликованных видеопримеров. Прежние постановочные AI-фото не используются на новой странице. assets/whatsapp-example.webp — вымышленный пример интерфейса WhatsApp, созданный ImageGen, не настоящая переписка.
- assets/examples/ содержит проверенные короткие фрагменты для витрины. Их форматы и проверки описаны в EXAMPLES.md. Все восемь роликов открываются по нажатию с синхронной оригинальной дорожкой.
- demo.mp4 на странице гостя — оригинальное синтетическое обычное видео: 8 секунд, без звука. Оно не является панорамной записью или реальным заездом.
- Блок «После заезда» показывает честный отзыв и повторное приглашение только с отдельного согласия гостя. Переписка вымышленная; сбор данных и отправки не подключены. Визуал и prompt — в AFTER_RIDE.md.
- Настоящий сферический пример добавляется после проверки панорамного исходника. Клиентские данные, необработанные материалы и ссылки на рабочие облачные папки в репозиторий не включаются.

До 70% — возможная доля выручки от видеопродаж на согласованных условиях, не обещание чистой прибыли. Окупаемость предлагается рассчитать по цене, оплаченным заказам, доле площадки и расходам, без гарантированных сроков.

## Коммерческая подача

Страница предлагает обсудить запуск и тестовый заезд. График содержит три расчётных сценария с открытыми допущениями, а не прогноз или результат клиента; выбор сценария работает локально без сбора данных. Ревью с позиции владельца, условия покупки и проверки — в SALES_REVIEW.md.

## Разработка и публикация

main публикуется на GitHub Pages. Изменения проходят через отдельную ветку, pull request и приёмку владельцем перед обновлением main. Файл .nojekyll сохраняется.

Главная открыта для индексации и указывает canonical https://muchosun.github.io/montage-360-preview/. В sitemap.xml включена только эта страница; guest.html сохраняет noindex/nofollow. После публикации карту сайта можно отправить в панели поисковых систем по адресу https://muchosun.github.io/montage-360-preview/sitemap.xml. Готовность к индексации не подтверждает включение в поиск или позиции по запросам.

Тема главной — монтаж видео 360° и обычных роликов для аттракционов и прокатов. Семантика по намерению, метаданные и проверки — в [SEO.md](SEO.md); кандидаты в минус-фразы для будущей рекламы — в [DIRECT_NEGATIVES.md](DIRECT_NEGATIVES.md). Частотность Wordstat не подтверждена, рекламные настройки не менялись.

Проверки видеовитрины перечислены в EXAMPLES.md; история редизайна — в REVIEW.md. Локальные артефакты проверки в output/ и служебные файлы браузера исключены из Git.

Текущая переработка дизайна, русских текстов и структуры описана в [UX_REVIEW.md](UX_REVIEW.md). Черновики рекламных форматов без запуска кампаний — в [AD_CREATIVE_BRIEF.md](AD_CREATIVE_BRIEF.md).
