# Интеграции и выпуск

## Метрика

Используется отдельный, уже созданный владельцем счётчик **114749900**, заданный публично в analytics-config.js. API-ключей и секретов в клиентском коде нет. Скрипт работает только на HTTPS montazh360.ru, пути / и /index.html. На HTTP, localhost, github.io, поддоменах и guest.html счётчик не загружается.

Одна инициализация и один tag.js, даже при повторном выполнении кода. webvisor=false, clickmap=false, trackLinks=false. В contact_click передаётся только канал phone/telegram/max, без номера, имени, URL контакта и текста сообщения. Это контактный клик, не заявка; цель не использовать для оптимизации рекламы. Владелец отдельно создал JS-цель lead_form_success.

В sessionStorage того же production-сеанса сохраняются только utm_source, utm_medium, utm_campaign, utm_content, utm_term: ограничены длина и управляющие символы. Остальные query-параметры не копируются. При новом наборе UTM старые метки заменяются; при переходе без меток — сохраняются. Есть read-only getter M360Attribution.get() для будущей отправки формы. Значения меток и данные заявки не передаются в reachGoal.

Контракт поведения проверяется командой node --test tests/analytics.test.cjs без сетевых запросов в Метрику. Подтверждение получения реальных событий панелью Метрики потребует выпуска и проверки владельцем; synthetic-тесты не накручивают счётчик.

## Вебмастер и домен

Владелец сообщил о созданном HTTPS-сайте в Яндекс Вебмастере и TXT в Рег.ру. Дополнительный метатег или HTML-файл подтверждения не добавляется. Статус подтверждения в аккаунте из этого окружения не проверялся.

В ветке canonical, og:url, og:image и sitemap переведены на https://montazh360.ru/. robots.txt находится в корне проекта и станет корневым robots.txt этого CNAME-домена. Sitemap включает только главную. guest.html остаётся noindex/nofollow; Disallow для неё не добавлен, чтобы робот мог прочитать метатег.

До выпуска:

1. Подтвердить валидный сертификат montazh360.ru и HTTPS в GitHub Pages, не меняя DNS из экспериментальной ветки.
2. После принятия PR проверить публичные HTML, /robots.txt, /sitemap.xml, OG JPEG и отсутствие X-Robots-Tag на главной.
3. В существующем Вебмастере проверить TXT-подтверждение и отправить HTTPS sitemap. Не создавать дубль сайта или счётчика.

Готовность к обходу не подтверждает индексацию, точный сниппет или позиции.
